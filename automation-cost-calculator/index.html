How to read this (the counting rules decide the winner)

  • Make counts every module action as one credit: reads, writes, searches, transforms, iterations. Routers and error handlers are free. Longer scenarios cost more per run.
  • Zapier counts every successful action step as one task. Triggers are free, and some built-in tools do not consume tasks (Formatter does not; Paths do when a branch runs), so a real bill can land on either side of the raw step count used here. Failed steps do not count.
  • n8n counts one full workflow run as one execution, however many steps it has. Step count is irrelevant on n8n Cloud; run count is everything. On the self-hosted Community Edition there is no execution meter at all. The 50,000-execution n8n figure is an estimate: n8n does not publish that tier's price.
  • Make figures above 10,000 credits are priced in 10,000-credit blocks at the plan rate, which matches how Make sells add-on credit packs. Confirm the live price on Make's pricing page before quoting a large volume.
  • Currency: Make and Zapier figures are USD. n8n prices in EUR; US visitors see about $20 (Starter) and $50 (Pro) per month on annual billing.
